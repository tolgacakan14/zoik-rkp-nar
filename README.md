# Zoi Kırkpınar QR Menü

Mobil odaklı, kategori ve ürün araması olan Zoi Kırkpınar menüsü. Ürünler altışar yüklenir; nargile menüsünde üç aromaya kadar seçilebilen etkileşimli 3B model bulunur.

```bash
npm install
npm run dev
```

Yerel geliştirme adresi terminalde Vite tarafından gösterilir. Statik çıktı için `npm run build` komutu `dist-local/` klasörünü üretir.

Menü fiyatları ve ürünleri `data/menu.json`, nargile aromaları `data/hookah.ts` içinde tutulur. Ürün görselleri `public/products/` klasöründedir. Fiyatlar yayımlanmadan önce işletmenin güncel menüsüyle doğrulanmalıdır.
